## 第一章 产品概述

### 1.1 产品定位

面向食用菌工厂化全产业链，把「菌包制备 → 灭菌 → 接种 → 培养 → 出菇 → 采收 → 冷链」七道工序，以及贯穿全程的环境、设备、质量、追溯数据，统一到一个后台和四类应用中。

| 端 | 承载角色 | 核心能力 |
| --- | --- | --- |
| PC 管理后台 | 企业负责人、生产主管、质检员、追溯专员 | 六组一级菜单，29 个菜单业务页 + 溯源配置与溯源统计；工序台账、设备管控、预警闭环、追溯赋码与存证 |
| 移动应用端 | 车间操作工、设备运维、质检、仓储 | 4 个主 Tab + 9 个现场作业入口；扫码开工、工序填报、过磅、抽检、预警处置、设备报修、冷库出入库 |
| 生产数据大屏 | 值班室、参观接待 | 单页 6 视图：运营总览 / 环境设备 / 视频监控 / 生产管理 / 能耗管理 / 质量追溯 |
| 消费者溯源 H5 | 消费者、监管抽查 | 免登录扫码查批次履历、出厂检测报告、链上存证验证、扫码风控 |

### 1.2 系统组成

| 模块 | 承载端 | 页面数 |
| --- | --- | ---: |
| PC 管理后台 | PC 浏览器 | 32 |
| 移动应用端 | 手机 / 微信 | 15 |
| 生产数据大屏 | 4K 大屏 | 1（6 视图同文件切换） |
| 消费者溯源 H5 | 手机浏览器 | 2 |
| 统一门户与引导页 | PC / 手机 | 3 |

### 1.3 建设范围

**本期包含**：生产台账、环境与设备管理、预警闭环、追溯赋码与链上存证、移动端现场作业、数据大屏可视化、消费者溯源、权限与运维。


### 1.4 原型形态说明

- 纯前端 HTML 原型，无后端、无构建步骤；数据用 `localStorage` / `sessionStorage` 模拟。
- 全站必须离线可用，**禁止引入 CDN 资源**。
- PC 与移动端数据尚未打通，本地数据仅用于演示。
- 全站 53 个 HTML 页面：PC 后台 32 · 移动端 15 · 数据大屏 1（6 视图）· 消费者 H5 2 · 引导页与门户 3。

## 第二章 端侧构成与导航

### 2.1 总体结构

```

 PC 管理后台      移动应用端      生产数据大屏      消费者溯源 H5
 applefarm_       applefarm_      applefarm_       applefarm_h5/
 backhand/        mobile/         dataanlye/       trace_h5.html
```

| 目录 | 说明 |
| --- | --- |
| `html/applefarm_backhand/` | PC 后台：登录、壳页、首页 + 29 个菜单业务页 + 溯源配置/溯源统计，共 32 个 HTML；`js/shared/fungi-store.js` 为统一主数据源 |

| 设备管理 | 设备管理 `device_info` · 设备环境数据 `env_monitor` · 设备运行监控 `device_control` · 设备运维工单 `device_maintain` · 备品备件 `device_spare` |

顶栏功能：侧栏折叠、三级面包屑、站内搜索（按菜单名/文件名跳转）、预警通知面板（按级别与来源筛选，未处理项带红点）、用户菜单（角色信息、修改密码、退出登录）、当前日期。

### 2.3 移动端导航

底部 4 个主 Tab：**首页** `mb_home` · **监测** `mb_device` · **监控** `vr_panorama` · **我的** `mb_mine`。子页面统一 `mb-back-bar` 返回，不加底部 Tab。

首页常用服务九宫格（固定顺序）：设备控制 → 设备报修 → 预警处置 → 扫码开工 → 工序填报 → 采收过磅 → 冷库出入库 → 质量抽检 → 杂菌识别。按登录角色显示高频入口，右侧「全部/收起」开关可展开完整九宫格（管理类角色直接显示全部 9 项并隐藏开关）：

| 角色关键词 | 高频入口 |
| --- | --- |
| 操作/工位/车间 | 扫码开工、工序填报、采收过磅、预警处置 |
| 运维/维修/设备 | 设备控制、设备报修、预警处置、工序填报 |
| 质检/质量/检验 | 质量抽检、杂菌识别、预警处置、采收过磅 |
| 仓储/冷库/库房 | 冷库出入库、采收过磅、质量抽检、预警处置 |
| 管理及未知角色 | 全部 9 个入口 |

### 2.4 大屏导航

单文件 6 视图，顶栏 Tab 切换，支持 `?view=overview|env|video|production|energy|trace` 直达。

### 2.5 H5 与门户

- H5 溯源页免登录，直接以 `?code=` 或 `?c=`（8 位短码）带参进入。
- 门户只做入口聚合与系统服务状态展示，认证在各端完成。

### 3.2 企业管理

企业档案与资质证书。

- **层级标识**：L1 厂区 / L2 车间 / L3 出菇房 / L4 层架 / L5 架位。
- **规则**：建档后不可删除，只能停用；在产节点或含在产下级的节点禁止停用；停用后版本号自增并写入变更历史（保留近 300 条）。

| Tab | 表格列 |
| --- | --- |
| 工艺 SOP | 编号、名称、版本、适用、生效日期、状态、关键参数摘要 |
| 配方模板 | 编号、名称、品种、版本、生效日期、作者、参数摘要、下发菇房、状态 |
| 接种等级 | 等级、名称、洁净度、沉降菌、污染率、判定说明 |

### 3.3 生产管理

七道工序对应七个页面，文件名与业务名不一致时以实际标题为准。

| 页面 | 业务 | 表格列 |
| --- | --- | --- |
| `material_io.html` | 菌包制备 | 配方批：配方号、菌株、配方配比、含水率%、pH、袋数、袋重kg、状态、操作人、时间。称重抽检：抽检批次、灭菌批号、装袋数、抽检频次、样本数、样本均重kg、标准kg、合格率%、已上架、守恒判定、操作人。库存变动流水：时间、类型、物料、数量、关联单据、经手人、备注 |
| `harvest_report.html` | 高压灭菌 | 灭菌单号、锅号、批次、袋数、保温min、峰值°C、曲线采集、操作人、复判、状态、时间 |
| `farming_record.html` | 无菌接种 | 接种批次：接种单号、批次、菌株、接种室、袋数、接种量、操作人、污染率%、时间。洁净度监测：记录编号、接种室、沉降菌cfu、粒子数、限值cfu、判定、时间 |
| `harvest_record.html` | 菌丝培养 | 培养单号、批次、架位、培养天数、满袋率%、温度°C、污染率%、上次翻堆 |
| `harvest_plan.html` | 出菇培育 | 培育单号、批次、菇房、潮次、温差°C、湿度%、CO₂ppm、光照lx、进度、预计采收 |
| `harvest_process.html` | 采收分拣 | 采收单号、批次、菇房、潮次、产量kg、一级kg、一级占比、人数、工时h、操作人、时间 |
| `harvest_storage.html` | 仓储冷链 | 库存批次：库存批次、库区、生产批次、品种、库存吨、保质期至、温度°C、状态。出入库流水：流水单号、类型、库区、生产批次、吨、操作人、时间 |

**关键业务规则**：

- **菌包制备**：每 50 袋抽 1 袋称重；上架数不得超过装袋数，超发红色阻断且不允许提交（提示「超发阻断：上架 N 袋 > 装袋 M 袋」）；出库/报废联动扣减物料库存，库存不足即阻断。配方状态：拌料 / 装袋 / 待灭菌 / 已灭菌。
- **高压灭菌**：温度曲线为控制器自动采集，**不可手补、不可删改**，仅能「追加说明」，删除操作硬阻断；按 SOP-02 自动判定——保温段最低探头温度 ≥121℃ 自动通过，<121℃ 转人工复判，曲线缺口标「待复判」。统计卡展示今日锅次、已完成、曲线缺口、平均保温（工艺要求 121℃ ≥ 120min）。
- **无菌接种**：**洁净度门禁**，未达 A/B 级禁止开工，C 级禁止放行并要求重新灭菌接种追责；洁净度合格判据为沉降菌 ≤ 限值 3.5 cfu；不合格提示「该时段接种批次需追溯复核，接种室应重新消杀并复测」；污染率 ≥3% 达预警线。
- **菌丝培养**：污染分档按污染率 ≥3% / 1%～3% / <1%；满袋率趋势图含工厂均值参考线 92.6%；积温与培养天数双条件判定转潮；记录翻袋与累计补水(L)。
- **出菇培育**：进度枚举 催蕾 / 菇蕾分化 / 子实体生长 / 采收就绪。
- **采收分拣**：**预冷交接**——按 kg/1000 生成 YL-01 库存批次、保质期 3 天，已交接单不可重复交接，删除采收单时不回退已交接库存。
- **仓储冷链**：库区 YL-01 预冷区 / LK-A 冷库A / LK-B 冷库B；**FIFO 优先出库**，保质期 ≤3 天的临期批次标红。

### 4.1 全链条九节点口径

后台全链条录入与数据大屏追溯视图共用同一套九节点定义（`trace_batch.html` 的 `NODES` 与 `da_index.html` 的 `TR_NODES` 逐字一致）：

| # | key | 节点名称 | 必填字段 | 次要字段 |
| --- | --- | --- | --- | --- |
| 1 | `strain` | 菌种 | 菌种编号 | 用量 / 代次（栽培种 15g/袋） |
| 2 | `bag` | 装袋 | 配方编号 | 含水率 %（62） |
| 3 | `sterilize` | 灭菌 | 灭菌锅号 | 峰值温度 °C / 保温 min（121°C 120min） |
| 4 | `inoculate` | 接种 | 接种室 | 沉降菌 cfu / 接种量（0.9 · 15g/袋） |
| 5 | `culture` | 培养 | 培养架位 | 培养天数 / 温度（24天 23.5°C） |
| 6 | `fruit` | 出菇 | 出菇房 | 潮次 / CO₂ ppm（第2潮 620ppm） |
| 7 | `harvest` | 采收 | 采收量 kg | 一级菇 kg / 人数（264kg 4人） |
| 8 | `grade` | 分级 | 分级结果 | 一级占比 %（82.5） |
| 9 | `cold` | 冷链 | 库区 | 入库吨数 t / 温度（1.4t 3°C） |

- 批次号格式 `MJ-YYMMDD-NN`，创建后进入 9 节点待录入状态。
- 阶段下拉 6 项：菌包 / 灭菌 / 接种 / 培养 / 出菇 / 冷链；品种 4 项：平菇 / 杏鲍菇 / 金针菇 / 香菇。

- 录入时间格式 `YYYY-MM-DD HH:mm`，操作人必填；节点支持「补录」与「重新录入」（后者覆盖原值）。
